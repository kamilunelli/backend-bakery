# Sistema de Gerenciamento de Padaria

Sistema desktop desenvolvido em Java com interface gráfica (Java Swing / JFrames) no Apache NetBeans para o gerenciamento operacional de uma padaria, integrando cadastros, controle de vendas e programa de fidelidade.

## Funcionalidades

- **Cadastro de Clientes:** registro, consulta, edição e exclusão de clientes.
- **Cadastro de Produtos:** gerenciamento do catálogo de produtos da padaria.
- **Controle de Vendas:** registro de pedidos e acompanhamento das vendas realizadas.
- **Programa de Fidelidade:** controle de pontuação/benefícios vinculados aos clientes cadastrados.

## Tecnologias Utilizadas

- **Linguagem:** Java
- **Interface Gráfica:** Java Swing (JFrames)
- **IDE:** Apache NetBeans
- **Banco de Dados:** PostgreSQL

## Como Executar

1. Clone o repositório:
   ```bash
   git clone [https://github.com/kamilunelli/backend-bakery.git](https://github.com/kamilunelli/backend-bakery.git)

2. Configure o banco de dados PostgreSQL e ajuste as credenciais de conexão no projeto (URL, usuário e senha).

3. Abra o projeto no Apache NetBeans.

4. Verifique se o driver JDBC do PostgreSQL está adicionado às bibliotecas do projeto.

5. Execute a classe principal pela IDE.
